# jnk-2-brainstorm — notes

Private notes for the human. The agent never sees this file.

**What:** Think together before committing to anything — explore the problem and candidate directions with no plans, no code, no verdicts.

**When:** the problem is fuzzy — "let's think" moments. Optional: use it first when fuzzy, use understand first when concrete.

**Why:** hammock-driven development: the answer forms when you stop forcing the problem. Deliberate thinking beats the automatic first answer.

**Fits:** the widening first pass of the double diamond; hands candidate directions to jnk-3-decide without a verdict.

**Refs:** Hickey (the hammock), Kahneman.
