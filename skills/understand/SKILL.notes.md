# jnk-1-understand — notes

Private notes for the human. The agent never sees this file.

**What:** Build a shared mental model of a codebase area before changing it — locate relevant code, map ownership, make unknowns explicit (IOUs).

**When:** fresh work, or after pickup — the first beat of the core arc.

**Why:** never change what you don't understand; ~70% of the flow is enough. Chesterton's Fence: don't take down a fence until you know why it was put up.

**Fits:** the model written here is the input to everything downstream — jnk-3-decide when concrete, jnk-2-brainstorm when fuzzy.

**Refs:** Chesterton, Feynman.
