# jnk-eval — notes

Private notes for the human. The agent never sees this file.

**What:** Evaluate how well the workflow's skills actually worked in a pi session transcript — per-skill verdicts with evidence, plus proposed edits held to the workflow's own standards.

**When:** a session went sideways, or quarterly — not routine.

**Why:** the failure instrument: judge the workflow by its receipts. An impression with no line number is not a finding.

**Fits:** audits the skills against their own standards; proposes edits, never applies them without approval.

**Refs:** Pocock (a skill fires when invoked and contains nothing that doesn't change behavior).
