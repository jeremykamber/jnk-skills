# jnk-3-decide — notes

Private notes for the human. The agent never sees this file.

**What:** Choose an implementation direction collaboratively before writing code — the product line, success with a measurable outcome, options through lenses, a decision record, a thread name.

**When:** a direction must be chosen.

**Why:** the narrow point of the double diamond. Judgment is the human's call; lenses beat vibes; no strawmen. A measurable output moves mountains — name it when one exists.

**Fits:** after understand/brainstorm; its record in docs/adr/ is what jnk-4-design confirms and routes. Squawk: decide + design could merge for trivial features — kept separate because direction and shape are different judgment calls; merge if gates feel heavy.

**Refs:** Hickey (simple vs easy), Metz (wrong abstraction), Fowler (Rule of Three), Kahneman, Horthy (measured by).
