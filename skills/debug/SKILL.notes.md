# jnk-debug — notes

Private notes for the human. The agent never sees this file.

**What:** Find and fix the root cause of broken behavior — reproduce first, diagnose with evidence, gate the diagnosis before fixing, verify on the original failure.

**When:** behavior is wrong and the cause is unknown.

**Why:** hypotheses are cheap, evidence is not. Reproduce before diagnosing — a bug you can't reproduce is a bug you can't diagnose.

**Fits:** a legitimate mode, not skipped beats; ejects to jnk-explore when the fix is large-scale.

**Refs:** Agans (the 9 rules), Zeller (delta debugging).
